# Microduck 中控 V297 测试版更新说明

本版基于 V296，先提供测试包，确认后再同步仓库。原生运动固件沿用 control.102。

## V297 修复

- 解决缺 IMU、缺某颗舵机时，模式切换长时间占着管理锁，连测试、编号也无法进入的问题。收到硬件初始化等待状态后及时释放本次管理任务，允许进入测试、编号处理接线或设备问题。
- 标定、运动页面保留具体故障设备的中文提示和关键原始错误；完整过程继续保留在系统日志。不会把“服务模式已设置”当成“硬件已就绪”。
- 清理运行包里的历代验证归档、堆叠说明、已弃用的透明接线图与未处理原图；保留当前白底图片、本版验证源码和必需运行文件。

## 本轮累计功能

- **四个独立模式**：IMU / HAT / HUB 测试、舵机编号、关节标定、机器人运动。左侧直接切换，错误使用网页内弹窗；初次启动显示准备页，SSH 连接后按实际状态引导。
- **编号工作台**：扫描 ID 1–250，显示进度并可停止；列表显示实际位置、对应关节与编号状态，选择目标编号保存。可选择已占用编号，交换两颗舵机的关节编号。
- **单颗中位校准**：将所选舵机当前位置设为 2048，只更新相关舵机，不要求重新扫描整个列表；该关节需重新标定。
- **硬件独立测试**：IMU 姿态、麦克风收音电平、扬声器鸭叫与播放电平；接线白底图放在同页。优先使用已有的较长鸭叫音源。
- **手柄直接带操作说明**：实物转绘手柄保留对应可操作位置、说明与呼吸光晕。摇杆和运动操作需先 HOME 并进入保持，卸力和叫声不受保持状态限制。
- **页面布局**：标定工作台按操作分列，保留较高的 3D 模型；运动模式 AI 单列，另一列为全关节反馈和关节曲线，上下对齐。摄像头、ToF 与系统状态集中显示。
- **反馈与状态**：扫描、改号、中位校准原位置更新；普通标签切换不主动重载页面；正常测试、编号停总线不当作运动故障。SSH 状态与机器人服务状态分开。
- **错误更易懂**：缺 IMU、缺舵机及标定不足有中文原因并保留原始错误。保留原有系统日志与维护事件，只精简成段 JSON 和多余末尾换行。
- **操作更集中**：固件与电源默认展开，移除重复的结束与核验入口；Logo 加入 kissqy，手柄连接修复入口更明显，模式卡片尺寸稳定。

当舵机尚未编号时，请单独连接单个舵机进行编号，不能串联多个未编号舵机，否则无法识别；已编号舵机可以串联。

## 测试边界

本版修复在中控侧完成，完整固件包和模型保持 V296 原样；无需为这次修复重刷或升级固件。已完成本地受控回归与打包校验，实机验收待完成；仓库和公开下载入口尚未更新。
